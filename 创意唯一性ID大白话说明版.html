第 1 部分

5 个关键要素，一张表看懂

平台认定你的广告身份时，看的就是下面这 5 类要素。每一类里包含的具体设置项如下：

关键要素 具体设置项 对广告主意味着什么
① 谁
平台自动识别		 客户身份 平台会自动识别你属于哪个经营主体。同一品牌无论开几个账户、几个主体，都会被认定为同一个"你"。所以靠多开账户来增加曝光机会，是行不通的。
2 投什么（共 4 个设置项）
② 投什么
（4 项）
你的营销目标 		营销目的 你想让用户做什么：买商品 / 留线索 / 装应用 / 看品牌。目的变了，整个广告的考核方式就不一样了。
营销对象 你具体在卖什么（哪个商品、哪个活动）。必须和你的落地页内容一致，否则会被平台标记，严重时拿不到流量扶持。
落地形式 + 转化路径 用户点进来后怎么转化（如：H5 表单 → 加企微；小程序 → 下单）。路径不同，相当于走了不同的转化通道。
优化目标 平台帮你优化什么动作（如点击、表单提交、激活、付费）。改了优化目标，平台会重新学习，相当于一条全新的广告。
3 怎么投（共 2 个设置项）
③ 怎么投
（2 项）
出价和计费方式 		出价策略 你用什么方式出价（标准出价 / 最大转化 / 目标 ROI 等）。不同策略 = 不同的竞价赛道。
计费方式 按曝光 / 按点击 / 按转化计费。不同计费方式 = 不同的流量类型，会分开独立竞争。
④ 素材像不像
平台自动比对		 素材内容指纹 平台会自动比对你的图片 / 视频 / 文案内容。这是判断"算不算重复"的核心：素材内容有明显差异才算不同，只改一两个字、只换封面不算。
⑤ 什么形式
广告形态		 创意形式 视频横版 / 竖版 / 卡片 / 多图 / 直播切片等。形式不同，用户看到的场景不同，即使素材内容一样也不会互相抢流量。
第 2 部分

每个要素到底管什么？

把上面 5 个要素按"它管什么、改了会怎样、什么操作不影响它"展开，帮你理解为什么有些操作"看起来改了但其实没用"。

1
谁 客户身份
管的是"这条广告是谁投的"。同一品牌 = 同一个身份，不管你开了几个账户。
  • 改了会怎样：事实上改不了——平台自动识别，你无法靠换主体来变成"另一个人"。
  • 什么操作不影响：换账户、换主体、换广告 ID，都不会让你变成新身份。
2
投什么（4 项） 营销目的 / 营销对象 / 落地形式+转化路径 / 优化目标
管的是"你投的是什么、想让用户做什么"。
  • 营销目的：买商品、留线索、装应用等；变了之后整个考核口径重算。
  • 营销对象：卖的具体商品/活动；必须和落地页一致，不一致会被标记。
  • 落地形式 + 转化路径：用户点进来后走哪条转化通道；改了相当于换了条路。
  • 优化目标：帮你优化点击还是付费等；改了平台会重新学习。
3
怎么投（2 项） 出价策略 / 计费方式
管的是"你用什么方式抢曝光、按什么方式结算"。
  • 改了出价策略 → 等于换了竞价赛道（比如从"最大转化"切到"目标 ROI"）。
  • 改了计费方式（曝光 → 点击）→ 等于换了流量类型，可以独立竞争。
  • 只调出价金额（50 元 ↔ 60 元）不算，出价金额不在认定要素里。
4
素材像不像 素材内容指纹
管的是"你的素材是不是换汤不换药"。这是判断重复的核心。
  • 算"不同"：视频/图片主体换了、文案重写了（卖点/利益点/受众变了）、主视觉明显不同。
  • 仍算"相同"：只改语气词（"釉色流转"→"釉色温润"）、只换封面不改视频、多图只换顺序、文案整体沿用。
5
什么形式 创意形式
管的是"用户用什么方式看到这条广告"。
  • 视频横版 vs 竖版 → 用户场景不同（横版适合 PC/朋友圈，竖版适合视频号/信息流）。
  • 卡片 vs 多图 vs 长图文 → 落地交互不同，各算各的。
  • 同素材换形式 ≠ 重复，可以视为不同身份。

第 4 部分 · 解法

5 类要素各自怎么改？5 条可执行建议

上文讲了 5 个要素"什么能改、什么不能改"。这一节直接给你对每个要素改就能获得"新身份"的具体操作——按重要性排序，越往后越涉及素材层面。
关键要素 具体设置项 你可以做什么操作 备注说明
① 谁 客户身份 （基本不可变，由平台自动识别）
想增加客户身份 → 必须按平台规则真实增加主体，不要用 hack 手段堆主体 		注意 增加客户主体、有概率增加新身份。注意使用差异化主体工商信息、经营信息的主体（属于 hack 系统行为，会酌情尝试）
② 投什么 · 通过改营销考核的 4 项获得新身份
② 营销目的 使用智投二级影响目的：专场放量 注意 保健食品暂不支持
营销对象 直播间商品表达 注意 保健食品暂不支持
落地形式 + 转化路径 直播 / 直购 / cid 多链路投放 建议 在营销目的对应的"链路"里选不同承接通道，链路不同即获得新身份
优化目标（OG） 多样化 OG 搭配（下单、下单 ROI、24 小时下单等） 建议 同一批素材可搭配多种优化目标投放，每个 OG 算独立身份
③ 怎么投 · 通过改出价 / 计费获得新身份
③ 出价策略 自动出价 / 手动出价 切换 建议 同一素材配不同出价策略，按赛道独立竞争
计费方式 全量通 CPA 结算 / 全店托管-原生内容加热 / CPA 结算开白 new 建议 不同计费方式 = 不同流量商品，独立计量、独立防卷
④ 素材像不像 素材内容指纹 产品动作（重）
  1. 引导 3.0 衍生 MAX 开关广告维度应开尽开
  2. 智投全库智选、项目维度应开尽开
  3. 智投 AIGC 开关，按客户对 AIGC 接受程度推进
  4. 直播-客户可增加直播实时画面推广
生产动作（重）
  • 客户自制拆新增加创意指纹
 重点 这是改造成本最高、但最核心的一环——前 3 类要素的差异通常很快会被同样素材耗尽，最终能否拉开差距，看的还是素材本身。
⑤ 什么形式 创意形式 卷形象视频、竖版横版版、同步可覆盖横版底存 建议 同一批素材做竖版 + 横版 + 多图等多种形式投放，可同时覆盖不同用户场景
提示 视频横版本身也建议做差异化（卷形象视频 / 竖版横版版）

使用顺序建议：先打通①②③三类的可改项（成本最低、上线最快）；④ 素材是中长期投入；⑤ 形式作为补充覆盖。不建议把力气放在堆主体、堆出价金额上——前文已说明这些不在认定要素里。

第 5 部分

这些操作不会让你获得"新身份"

有些操作你可能以为"换了就等于新广告"，但实际上不在认定要素里，不会带来额外曝光机会：

✅ 会改变广告身份（在认定要素里）
  • 客户身份（平台自动识别）
  • 营销目的 / 营销对象 / 落地形式+转化路径 / 优化目标
  • 出价策略 / 计费方式
  • 素材内容指纹（有明显差异才算）
  • 创意形式（横版↔竖版等）
❌ 不会改变广告身份（不在认定要素里）
  • 换账户（多开账户不增加新身份）
  • 复制广告（复制粘贴不算新广告）
  • 换主体（同一品牌多主体还是同一个"你"）
  • 调出价金额（出价高低不换赛道）
  • 调定向（地域/年龄/兴趣等人群不换身份）

为什么这么设计？平台希望让真正优质的广告拿到公平竞争的机会。靠复制账户、复制广告、调出价来"刷"曝光量的做法，在新规则下不会再带来额外机会。把精力放在打磨差异化素材和深耕优质账户上，回报更长期。

第 7 部分

常见问题

Q1：5 个要素是不是必须全改才算不同？
不是。只要 5 个里有任意一个不同，就认为是不同身份。不需要同时改 5 个。
Q2：同素材换横竖版真能"不算重复"吗？
不算违规。平台认为横版竖版是不同的广告形态，用户看到的场景不一样。但如果你横竖版素材被同一人群看到，建议素材本身也有差异，否则用户体验上仍会感觉重复。
Q3：同一品牌开了多个主体，会被认成几个身份？
只会被认成 1 个。平台自动识别经营实体，同一品牌的多主体归到同一个身份，多开主体不会增加新身份。
Q4：创意形式指的是什么？
指广告的展示形态：视频横版 / 竖版、卡片、多图、直播切片等。同一条素材换成不同形式，算不同身份。
Q5：我把同一条视频投到两个账户，为什么拿不到双倍曝光？
因为 5 个要素全没变，平台认定是同一条广告。多开账户投放同一素材，不会带来额外曝光机会。建议把精力放在打磨差异化素材上。
精而强 > 多而糙 · 把精力放在打磨优质素材上，平台会给你更公平、更长期的回报
